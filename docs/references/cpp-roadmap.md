## 一、C++ 学习清单 & 掌握程度

### 梯度0：C 语言基础（地基）

✅ 学习内容
指针、内存布局、数组、字符串、`malloc/free`、结构体、函数指针、可变参数、预编译宏、头文件、`static`、`const`、`typedef`、内存四区（栈/堆/全局/常量区）、`volatile`。

✅ 掌握程度

- 能手写链表、队列；能识别野指针、内存泄漏、悬垂指针；
- 看懂 C 风格回调、函数指针；理解宏的各类坑；
- 能看懂 FFmpeg、Linux 系统调用的 C 接口。

### 梯度1：C++ 面向对象基础（面试高频）

✅ 学习内容
类、访问控制、构造/析构、拷贝构造、拷贝赋值、`this`、友元、`static` 成员、`const` 成员、初始化列表、继承、多态、虚函数、虚表、虚继承、RTTI。

✅ 掌握程度

- 讲清虚表布局、菱形继承二义性、虚继承底层解决思路；
- 分清什么时候必须自定义拷贝、什么时候可以使用默认版本；
- 理解析构函数为什么推荐 `virtual`，以及禁止 virtual 的场景。

### 梯度2：现代 C++ 核心（C++11 ~ C++17，重中之重）

✅ 学习内容

- 值类别：左值、右值、纯右值、将亡值；普通引用、右值引用、转发引用
- 移动语义、移动构造、移动赋值、`std::move`、`std::forward`、完美转发
- 智能指针：`unique_ptr` / `shared_ptr` / `weak_ptr`、控制块、循环引用、自定义 deleter
- Lambda、捕获、`mutable`、`std::function`、`std::bind`
- 模板基础：函数模板、类模板、模板特化、可变参数模板基础
- `auto`、`decltype`、`decltype(auto)`、`constexpr`、`noexcept`
- STL 容器：`array`、`vector`、`deque`、`list`、`map/set`、`unordered_map/unordered_set`、`string`
- 迭代器失效规则（vector 扩容、map 删除、unordered_map rehash）
- 算法库 `<algorithm>`：`std::sort`、`std::find`、`std::remove`
- `std::span`（C++20，视图，音视频缓冲区高频）
- 原子：`std::atomic`、内存序 `memory_order` 基础
- 多线程：`std::thread`、`mutex`、`lock_guard`、`unique_lock`、`condition_variable`

✅ 掌握程度

1. 口头讲清值类别、移动语义、完美转发，手写简单 demo；
2. 三种智能指针的适用场景、shared_ptr 开销、循环引用解决方案；
3. 每个容器底层结构、时间复杂度、迭代器失效场景；
4. 独立写生产者消费者模型，理解互斥与同步；
5. 区分 `std::array`（内联存储）、`vector`（堆存储）、`span`（视图，不持有内存）。

### 梯度3：工程进阶（简历加分、音视频/服务端刚需）

✅ 学习内容

- 内存池、对象池、环形缓冲区 ringbuffer（流媒体、网络框架高频）
- ABI、名字修饰、静态链接 / 动态链接、`.so` / `.dll`、`dlopen`
- RAII（C++ 核心思想）、异常
- 类型萃取 `type_traits`、SFINAE 基础（看懂即可，不要求精通模板元）
- C++20 协程（可选，游戏服务端、高并发网关热门）
- 性能：内存对齐、padding、cache line、false sharing（伪共享）、`perf` / `valgrind` 基础使用

✅ 掌握程度

- 资源优先使用 RAII 管理，拒绝裸指针手动 delete；
- 解释对齐、缓存行、伪共享现象，给出规避方案；
- 分清静态库、动态库、符号冲突、弱符号；
- 协程属于加分项，主线吃透后再学。

### 不需要深挖的内容（普通后端/音视频岗）

- 复杂模板元编程、重度编译期计算、Boost 冷门特性
- C++23 前沿冷门特性
- OpenGL / Vulkan 渲染管线（客户端渲染方向才需要）

### C++ 自检清单

- 区分左值/右值、完美转发，手写 move-only 类
- 掌握 unique_ptr / shared_ptr / weak_ptr 的全部常见坑
- 说出每个 STL 容器底层、复杂度、迭代器失效场景
- 手写生产者消费者，condition_variable 使用正确
- 使用 RAII 封装句柄、锁、缓冲区
- 理解 cache line、false sharing、内存对齐

## 二、408 CS 基础：学到什么程度（求职版）

> 
> 核心目标：可以独立写 Reactor 网络框架；看懂 Linux 网络栈行为；算法题稳定输出；解释工程里延迟、卡顿、内存、缓存现象。
> 不要求背诵考研简答题、冷门证明题。

### 数据结构（算法面试核心）

✅ 学习内容

- 线性表：数组、链表、栈、队列、环形队列
- 树：二叉树、BST、AVL、红黑树（理解思想，不用手写旋转）、B+树（数据库核心）
- 图：BFS、DFS、Dijkstra、拓扑排序
- 排序：快排、归并、堆排；排序稳定性、时空复杂度
- 哈希：哈希函数、冲突解决、负载因子、rehash
- 并查集、单调栈、滑动窗口、贪心、基础动态规划

✅ 掌握程度

- LeetCode 中等题稳定实现，独立分析复杂度；
- 解释 `std::map`（红黑树）、`unordered_map`（哈希表）；B+树适合数据库的原因；
- 可以根据场景选择数组、链表、环形 buffer。

❌ 不用：竞赛级 DP、高级图论、可持久化数据结构

### 计算机组成原理

✅ 学习内容

- 补码、大小端、IEEE754 浮点数
- 存储层次：寄存器、L1/L2/L3 Cache、主存、磁盘；局部性原理
- 虚拟内存、页表、TLB、缺页中断
- 流水线、分支预测（简单了解）

✅ 掌握程度

- 解释 CPU 缓存、伪共享、内存对齐、大小端；
- 理解虚拟内存，知道 `malloc` 不会直接分配物理内存；
- 理解浮点数精度问题（音视频、信号处理高频踩坑）。

❌ 不用：流水线冒险、磁盘调度算法、MESI 缓存一致性协议细节（知道名字与作用即可）

### 操作系统（后端/流媒体核心）

✅ 学习内容

- 进程、线程、PCB、调度、状态切换；进程与线程区别
- 并发：临界区、互斥、同步、死锁四个必要条件
- IO 模型：阻塞IO、非阻塞IO、IO多路复用 `select/poll/epoll`、信号驱动、异步IO
- 信号、管道、共享内存、消息队列
- 文件系统：inode、pagecache、预读

✅ 掌握程度

- epoll LT / ET 触发模式、坑点、Reactor 模型；
- 解释惊群效应；
- 区分进程上下文切换、线程上下文切换开销；
- 理解 swap、OOM、page cache 对流媒体读写的影响。

❌ 不用：各类调度算法公式、IPC 冷门特性

### 计算机网络（流媒体、WebRTC 刚需）

✅ 学习内容

- TCP/IP 四层模型
- IP、子网、路由基础
- TCP：三次握手、四次挥手、滑动窗口、拥塞控制、慢启动、快重传、粘包问题
- UDP：特性、适用场景（RTP、WebRTC）
- HTTP 1.1 / 2 / 3，长连接、分块、缓存
- 音视频应用层：RTMP、HTTP-FLV、HLS、RTP/RTCP

✅ 掌握程度

- 给出 TCP 粘包解决方案；理解 UDP 适合低延迟实时场景的原因；
- 解释流量控制、拥塞控制；
- 看懂简单 Wireshark 抓包（TCP / RTP）。

❌ 不用：BGP、OSPF 等路由协议细节、网络安全冷门协议

### 408 一句话验收标准

> 
> 原理能解释、简单代码能写、现象能归因；不追求背诵标准答案。

## 三、整体执行学习顺序

> 
> 你已有 C++ 入门基础，推荐顺序：

1. 巩固现代 C++（值类别、移动、智能指针、容器、多线程、RAII），同步刷 LeetCode
2. 补操作系统（进程线程、epoll、IO模型） + 计算机网络（TCP）
3. 手写简易 Reactor 异步网络 Demo（C++）
4. 音视频基础概念 + FFmpeg 命令行 + FFmpeg C API
5. 流媒体协议 RTMP / HTTP-FLV / HLS / RTP，研读 ZLMediaKit
6. 进阶可选：WebRTC、性能调优、内存池、C++20 协程

> 
> 若后续转向 Agent / RL：CS 基础完全复用，额外补充概率论、机器学习、强化学习。

## 四、音视频方向附加自检清单（备选路线）

## 五、学习原则与避坑提醒

1. C++ 不要孤立学语法：每学一个特性，思考网络/音视频场景下什么时候适合用；
2. 408 不要长时间啃书不写代码：边学原理、边刷题、边写小 demo；
3. 简历项目优先级：简易 Reactor 网络框架 + FFmpeg SDL 播放器 + ZLMediaKit 二次改造；
4. 优先 Linux 开发环境；Windows 仅用于调试；线上流媒体、服务端全部跑 Linux；
5. 不要过早钻进 H.264/H.265 编码内核：普通流媒体开发很少手写编码器，属于芯片算法岗范畴。
